# 通道修复与成熟实现对照（2026-10-04）

基于 cc-connect dfad194 和 Tencent/openclaw-weixin 24de5c9 的实际源码复核。
桥接沿用自研的持久队列与 MCP Events / dot 适配；不引入 Agent Engine、模型或命令解释器。

| 实际缺口 | 本次处理 | 证据与边界 |
| --- | --- | --- |
| 带说明的图片发送失败 | 按腾讯方式先发文字、再发媒体，分别保存结果 | 失败原图重试两部分均 accepted；手机端本人已确认 |
| message_id=0 导致重复判定 | 优先有效 ID，再用 item ID / client ID / seq 组合 | 回归测试 |
| 引用图片重复占空间、下载状态脱节 | 引用关联原附件，共享内容和下载状态 | 重启、下载状态及引用测试 |
| 失败后无法在工具中恢复 | retry_weixin_operation 重试明确失败的发送或附件下载 | 保留已接受部分；不自动重放 uncertain |
| 收到事件但无法知道 dot 是否读过 | 记录最近工具名、固定结果类别和时间 | 不记录正文、凭据或参数；旧历史不能据此反推 |
| 进度回复结束输入提示 | reply 工具增加 final:false；report_weixin_progress 续期 / 结束 | 处理状态与是否已有回复独立，五分钟租期 |
| 普通音频无法转换微信语音 | 可选 FFmpeg + silk-wasm 本地转换；SILK 可提供 WAV 预览 | 真实 WAV→SILK→WAV 回归；接收与转写已确认；本人取消语音回传必做验收 |
| Markdown 正则不完整 | 直接复用腾讯 StreamingMarkdownFilter，保留 MIT 许可 | Node 24+；无 Node 时使用简化纯文本降级 |
| 轮询错误固定频率重试 | 失败指数退避至 30 秒，成功复位；采用服务端轮询时长 | 本地协议测试 |
| 收到 -14 后永久停用 | 腾讯相同的一小时冷却后恢复轮询，持久化冷却 | 手动暂停会取消自动恢复；HTTP 401/403 不推断能自行恢复 |
| 限流后继续连续发送 | HTTP 429 分类、30 秒发送冷却 | 明确失败可重试，不自动重放未知送达结果 |
| 停服务等待长轮询 | 取消在途微信连接；发送中断仍保留 uncertain | 单实例绑定锁保持 |
| 附件缓存无回收 | 每小时回收超过 7 天的已完成缓存、24 小时未完成上传 | 保护待处理 / 待发 / uncertain 引用；保留消息正文和备份 |
| 文本文件也要 base64 | stage 工具支持 text_content | 原样 UTF-8 入库；二进制仍可分块 |

## 运行与配置

音频安装：`bash scripts/install-codecs.sh`。依赖固定为 silk-wasm 3.7.1 与 imageio-ffmpeg 0.6.0；不修改认证文件、全局代理或服务配置。FFmpeg 构建自身的许可证保留在安装目录，发布二进制时须单独处理相应许可义务。

可在本机配置中设置 `media_policy`：`cache_mib`（默认 256）、`retention_days`（默认 7）、`upload_hours`（默认 24）。单附件 20 MiB、音频预览/转换最多 300 秒是本桥接资源预算，不是微信官方上限。仅本人有配置权。

回滚：停止唯一用户服务，将生产 worktree 切回上一版本后启动。数据库变更是添加表 / 列，旧版可忽略。保留升级前私有数据库备份；不要用旧备份覆盖升级后收到的消息。缓存已回收的字节不能靠代码回滚恢复；有源地址的附件可尝试 retry 工具重新下载，源地址可能失效。

## 尚需平台或手机验证

- 自动 dot 事件任务是否启用、使用了什么任务指令和工具版本，服务器无法读取平台内部运行状态。需要原 dot 报告；不擅自新建第二个任务或订阅。
- 文件回传、语音接收/转写、两条旧图引用回复已由本人确认；视频回传、进度加长文、生成 TXT 文件随后也已由本人确认通过；任意云端二进制文件导出仍未验证。
- dot 云端生成文件自动导出到服务器没有已验证的文件传输接口；目前支持收到附件回传、分块暂存、文本文件及公开 HTTPS 文件导入。仅可访问公网 HTTPS，不转发认证头；不把 sandbox 内部路径当作服务器路径。
- dot 内部逐 token 思考和每个工具阶段不是 MCP Events 提供给桥接的数据。输入提示和进度基于实际读取及显式 progress / final 报告。
- 延迟优化、dot 主聊天历史同步按用户要求暂缓。群聊、多用户、Agent 斜杠命令不属于本人私聊通道目标。

后续运维、自动类型、文件导入与发布完善见 OPERATIONS.md、INSTALL.md、ACCEPTANCE.md。原 dot 已重建唯一任务并观察到自动处理工具链，平台长期持续执行仍需运行观察。
