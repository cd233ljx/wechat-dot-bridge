## 不混入的 Agent 功能

模型选择、Agent 会话切换、工作目录、Shell 执行、权限批准命令、Cron 主动推送、群聊 / 多账号路由属于另一层，不由本微信通道接管。斜杠消息作为用户文本交给原 dot，不在服务器截获执行。

## 明确的能力边界

- 没有额外 ASR / TTS 模型或付费模型 API。微信没提供转写时，桥接不会自动识别语音；本机已安装可选 FFmpeg / SILK 转码器，仅转换编码，不生成语音、不做语音识别。
- 文件 / 视频原样传输与 dot 能否理解其内容是不同能力；图片提供原生 MCP 图像，文本文件另提供可读文本，其他文件以 MIME 资源分块提供。
- 引用缓存只包含桥接见过的消息；它不是 OpenClaw 或 dot 主聊天历史迁移。
- 单附件 20 MiB、总缓存 256 MiB；超过七天的已完成附件缓存定期回收，待处理和待发送内容保留；预算可配置。长回复单次 256 KiB。预算均为本版实现值，不是微信上限。
- 延迟优化、dot 主聊天消息列表同步按用户要求暂缓。

## 一次性真人验收

刷新同一个插件至十个工具，保留当前订阅和绑定。依次验证图片描述及原图回传、文件 / 视频回传、语音、引用文字 / 图片、多次回复和长文分段。只记录成功状态及错误类别，不把原文、CDN 地址、密钥或完整数据库写到仓库。

本次实际缺口、修复证据及仍需真人验证的项目，见 [通道修复对照](CHANNEL_REPAIR.md)。
